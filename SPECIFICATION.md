# WSN Simulator Specification

Version: 0.1.0

## 1. Objective

Develop a wireless sensor network simulator for studying:

- Multi-hop communication from sensor nodes to sink node
- Minimum-hop routing
- Energy-aware rerouting
- Network energy consumption
- Network lifetime
- Sensor data transmission
- Data compression and encryption
- Fake sensor and fake data detection
- Battery exhaustion attack prevention
- Clustering and edge processing

---

## 2. Simulation Area

The simulated area is a rectangular region:

- Width: 2000 meters
- Height: 2000 meters

Coordinate system:

0 <= x <= 2000
0 <= y <= 2000

---

## 3. Sensor Network

Total number of sensor nodes:

500

Sensor nodes are randomly deployed over the simulation area.

Each sensor contains:

- Unique ID
- X coordinate
- Y coordinate
- Sensor type
- Initial energy
- Remaining energy
- Transmission range
- Neighbor list
- Node state
- Relay state

---

## 4. Sensor Types

The network contains five sensor types:

- 100 temperature sensors
- 100 humidity sensors
- 100 PM2.5 sensors
- 100 wind sensors
- 100 water-quality sensors

Total:

500 nodes

---

## 5. Sink Node

Default sink position:

x = 1000 m
y = 1000 m

The sink is assumed to have unlimited energy.

---

## 6. Energy

Initial energy:

2 Joules per sensor node

Low-energy threshold:

20% of initial energy

Therefore:

Energy threshold = 0.4 Joules

When:

E <= 0.4 J

the node must no longer be selected as a relay under normal routing.

When:

E <= 0

the node is considered dead.

---

## 7. Communication

Default transmission range:

200 meters

Two nodes are neighbors when:

distance(i, j) <= 200 m

Communication will support multi-hop routing.

---

## 8. Packet

Default payload size:

128 bytes

Sensor sampling interval:

10 seconds

Each packet will eventually contain:

- Source ID
- Sequence number
- Timestamp
- Sensor type
- Payload
- Security information

---

## 9. Simulation Model

The simulator uses a round-based model.

Each round may contain:

1. Sensor sampling
2. Packet generation
3. Route selection
4. Packet transmission
5. Packet reception
6. Energy update
7. Node-state update
8. Metrics collection

Maximum default simulation rounds:

10000

---

## 10. Routing Requirements

Routing development will contain:

1. Direct transmission baseline
2. Minimum-Hop routing
3. Energy-Constrained Minimum-Hop Routing (ECMHR)

ECMHR requirements:

- Prefer the route with the minimum number of hops.
- Nodes below the energy threshold cannot be normal relay nodes.
- A replacement route must be found when a relay becomes low-energy.
- If several routes have the same number of hops, prefer the route with better residual energy.

---

## 11. Security Requirements

Later stages will include:

- Node authentication
- Fake sensor detection
- Fake data detection
- Replay attack prevention
- Flooding attack detection
- Battery exhaustion protection
- Rate limiting
- Trust evaluation

---

## 12. Metrics

The simulator will eventually measure:

- Generated packets
- Sent packets
- Received packets
- Lost packets
- Generated bytes
- Delivered bytes
- Packet Delivery Ratio
- Throughput
- End-to-End Delay
- Energy consumption
- Energy efficiency
- Average hop count
- First Node Dies
- Half Nodes Die
- Last Node Dies
- Attack Detection Rate
- False Positive Rate
