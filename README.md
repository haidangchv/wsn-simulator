# WSN Simulator

Wireless Sensor Network simulation project.

## Current status

Stage 0 - Project specification and environment setup.

## Default network

- Area: 2000 m x 2000 m
- Sensors: 500
- Sink: (1000, 1000)
- Initial energy: 2 J
- Transmission range: 200 m
- Packet payload: 128 bytes
- Energy threshold: 20%

## Development roadmap

1. Random sensor deployment
2. Neighbor graph
3. Minimum-Hop routing
4. Energy model
5. ECMHR routing
6. Sensor data generation
7. Compression and encryption
8. Security attacks and defenses
9. Clustering and edge processing
10. Experimental evaluation
